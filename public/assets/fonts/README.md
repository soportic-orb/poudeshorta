# Tipografies

Totes dues estan allotjades en aquest servidor: el web no fa cap crida a
servidors externs per carregar-les.

| Família | Ús | Llicència |
|---|---|---|
| **Caveat Brush** | Titulars i elements destacats | SIL Open Font License 1.1 (`OFL-CaveatBrush.txt`) |
| **Nunito** | Text corrent (pesos 400, 700 i 800) | SIL Open Font License 1.1 (`OFL-Nunito.txt`) |

De cada família hi ha els subconjunts `latin` i `latin-ext`, que cobreixen els
caràcters del català, inclosos els accents, la ce trencada i el punt volat.

Els correus i les entrades en PDF **no** fan servir aquestes lletres: els
gestors de correu no carreguen tipografies externes de manera fiable i el PDF
utilitza les fonts bàsiques, que es veuen igual a qualsevol lector.
